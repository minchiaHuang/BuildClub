# Build Club

**Recite** — an AI mystery shopper that shows agencies whether ChatGPT recommends their clients, who it recommends instead, and what to change.

Built during the UTS Startups × Build Club 8-week AI Build Sprint (Sep–Nov 2026).

## Structure

- `PROJECT_CONTEXT.md` — concise current snapshot of the project (start here, also for AI tools)
- `docs/`
  - `PRD.md` — product requirements and definition
  - `mvp-scope.md` — what's in and out of the MVP, open questions
  - `decision-log.md` — key decisions, pivots and why
- `research/`
  - `user-research.md` — pain points, survey and interview insights
  - `competitors.md` — competitor landscape, gaps and positioning
- `app/` — product code

The Miro board is the working source of truth; these docs are synced from it.
