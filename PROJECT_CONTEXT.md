# Build Club Project Context

## Product
We are building an AI search visibility / GEO product.

It acts like a mystery shopper for AI search by testing how different users might ask ChatGPT, Claude, Gemini, and similar tools for recommendations.

## Problem
Businesses do not understand why AI tools recommend competitors instead of them.

## Target Customers
Primary:
- SEO agencies
- Digital marketing agencies

Secondary:
- Brands
- In-house marketing teams
- Startups

## Current MVP Direction
1. User enters a company or domain
2. User defines personas or customer types
3. System generates realistic AI-search queries
4. Queries are tested across selected AI platforms
5. Results compare which brands are mentioned
6. System explains likely reasons for visibility differences
7. System suggests improvements

## Current Stage
Build Club MVP sprint

## Product Principles
- Keep MVP narrow
- Explain why, not just what
- Make outputs actionable
- Focus on agencies first
- Validate before overbuilding
