# MVP Scope

## Goal
Build a simple AI search visibility tool for Build Club that helps businesses understand whether they appear in AI recommendations and why.

## Primary User
SEO agencies and digital marketing agencies.

## Core Problem
Businesses do not know why AI tools recommend competitors instead of them.

## MVP Must Have
- User enters a brand/company
- User enters or generates a few customer personas
- System creates realistic recommendation queries
- System runs those queries across selected AI tools
- System records which brands are mentioned
- System compares visibility across personas
- System gives simple explanations and recommendations

## Not in MVP
- Automatic website changes
- Browser extension
- Complex dashboards
- Full enterprise account system
- Large number of AI platforms
- Advanced analytics
- Team collaboration

## Success Criteria
The MVP should let us test whether users find the visibility comparison and recommendations useful.

## Current Open Questions
- Which AI platforms do we support first?
- How many personas should one test use?
- How many queries should be generated?
- How should we score visibility?
- What evidence should support recommendations?
