Trend Finder: three directions

Design review, 28 Oct 2026. Phases 1 to 3 only; the app is unchanged. Covers are coloured stand-ins because the sample data has none; live TikTok searches already return real covers (Thumb.tsx), which these layouts are built for. Every number shown exists in the data: views, usual (median) views, followers, outlier multiple, stage, account count, shares and saves, days ago, length.

Version 1: Contact Sheet

Pitch. The interface disappears and the covers become the page. A near-black gallery with square corners, wide gutters and no card chrome, in the spirit of a photographer's contact sheet (and the founder's Cosmos reference). Each cover carries one number, its outlier multiple, set like a frame number. Everything else waits for hover or focus. It is the strongest answer to "make the content the hero" and the most radical change from today.

Version 2: The Chart

Pitch. Trend Finder as a weekly music chart for content. Patterns are ranked like singles: big numerals, a serif title, the stage written like "re-entry" or "climbing", and a reel of the posts that prove it. It is editorial and warm, builds on the Altitude yellow and Sentient serif the founder already approved, and it is the best direction for answering "why is it trending?" and "is it worth copying?" at a glance, because the pattern, not the single video, is the unit.

Version 3: Lightbox

Pitch. A bright working table for picking content, built on the Pinterest interaction the founder liked, not its look. Variable-height masonry, plain text tabs, and hover that reveals a red Save and the "usual → this" bar. A persistent plan tray on the right turns saving into the start of a plan, so Discover → Save → Adapt happens on one screen. It is the most familiar and lowest-risk direction, and keeps today's green accent.

Interaction rules (all versions)

PreviewHover or focus for 400ms starts muted playback of live videos (cover zoom 1.02 for sample data). Leaving stops it. Never autoplay on scroll. Reduced motion: no zoom, no autoplay; a play icon appears instead.
KeyboardTab moves between tiles in reading order; Enter opens detail; S saves; J/K next/previous inside detail; Esc closes and returns focus to the tile (existing useShortcuts.ts). Focus ring always visible, 3px, never removed on mouse use for the grid.
FilteringStage/pattern tabs filter in place, update the count, keep scroll at top of grid, and write to the URL so Back works. Empty filter result says which filter and offers "Show all".
DetailDesktop: right-side panel 560px with the grid still visible and dimmed, so J/K browsing feels continuous. Mobile: full screen, swipe down to close.
SaveOptimistic, with undo for 5s. Saved count in nav updates. In V3 the tile animates to the tray (200ms; skipped under reduced motion).
Loading / errorSkeletons match final layout (masonry blocks or ruled rows). Live search errors show inline above the grid with the query kept and a retry button.
Responsive390px: 2-column grid, filters scroll horizontally, query bar in header, multiple stays on cover, caption always on (no hover on touch).

Recommendation

Version 2 (The Chart) for results and landing, borrowing Version 1's cover treatment (one multiple on the cover, metrics on hover) for the "All videos" view and Version 3's plan tray as the save destination. The Chart is the only direction whose structure answers "why is it trending?" without opening anything, it continues the Altitude yellow and serif the founder chose, and it has an identity no SaaS template has. Version 1 is the purest "content as hero" if the founder prefers a gallery feel; Version 3 is the safe fallback.
